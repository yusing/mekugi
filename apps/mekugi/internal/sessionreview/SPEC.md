# Session review

Session review joins authorized attachment membership with completed change
delivery and optional live previews. It owns the selected scope and subscription,
independently of provider request preparation and terminal rendering.

Validated request ancestry and authorized restored threads expand the scope.
Switching retires the previous attachment; subsequent request observations must
belong to the new lineage. Retained changes are delivered only after successful
[publication](../../../../docs/contracts/record-publication.md) and only to an
included thread and workspace. Scope snapshots remain immutable after delivery.

Membership and retained changes precede sampled previews. Replaceable preview
updates coalesce without delaying completed receipts; an overflowing subscriber
must resynchronize. Scope exhaustion pauses review and previews with a notice,
while capture and retained change commands remain available.

Closing or replacing the attachment retires its preview observation and delivery,
not captures, commands or host-owned work. Omitting Live Preview leaves saved
review and captured Activity receipts available. Evidence hydration belongs to
the application consumer and does not block this delivery owner.

Acceptance covers immutable membership, unrelated-thread isolation, subscriber
overflow, scope-before-preview ordering, optional preview absence and replacement
without changing capture or execution lifetime.
