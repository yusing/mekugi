# Router-owned commentary projection

## CTR-COMMENTARY-001 — Router-owned operation and subagent commentary projection

`CTR-JOURNAL-001` owns authored progress, durable journal state, and terminal delivery.
This boundary owns automatic operation notices, observed child activity, provider-usage
display, critical session notices, and exact generated-message provenance. Commentary
never replaces substantive tool or provider output.

A bounded authenticated publication broker accepts runtime notices for the originating
thread and author. Durable replay retains exact generated IDs before exposure so resume
and forks can remove only known generated history. Auxiliary capacity cannot evict
executable replay or alter command completion. Required journal retention follows the
stricter journal failure contract.

Child activity is attributed from validated stable thread relationships and canonical
agent identity, never session IDs or message text. The collector coalesces eligible
operations, starts, replies, completed commentary, usage, and critical errors for deferred
root delivery. It drains atomically at response-event boundaries; idle streams wait for
the next boundary rather than being extended. When the agents pane owns a root, the
collector delivers that root's events directly to the integrated terminal view
instead, and drains yield only the pane's one-time notices. Pane ownership,
acknowledgement after flush and inline fallback belong to
the collector. Main activity and visible reasoning snapshots are pane-only and cannot fall back
into model-visible commentary. Response admission requests the pane before tool
execution. The viewer only presents what it is given. Codex retains scheduling, recipients,
interrupts, waits, and assignment lifecycle.

Completed explore-filter observations use the same collector and integrated
pane view, with originating call identity and a typed measurement payload.
They can originate at the root as well as a child and never fall back inline.
The filter owns local stdout reduction measurements; the pane only renders them.
TypeSafe usage belongs to a separate bucket in the existing per-thread usage
owner, not the activity collector or the agent-model cost and mentor counters.

Provider-authoritative usage is accumulated per stable thread for the router lifetime.
Unknown prices preserve token totals but suppress cost claims. Missing responses preserve
known observed totals with explicit gap counts; identity conflicts and arithmetic overflow
make the affected cumulative total unavailable. Usage display
occurs only at main completion before its journal flush. It joins separate per-thread totals
through proven workspace ancestry into the selected compact or table presentation, without
mutating the underlying thread accounting. Main-turn usage has a separate bounded index keyed
by canonical thread/turn identity, never by provider attempt or a child's turn ID. Mentor
switch notes are acknowledged only by successful delivery of the usage message carrying them.
Metrics use the same terminal facts but retain independent calculation and persistence.

Critical notices use a separate bounded queue for failures that occur before ordinary
publication exists. Only display-safe classified details are rendered; other errors use
opaque references. Notices are acknowledged only after successful delivery and are
removed from later provider context by exact provenance, not text resemblance.
