# Controlled comparisons

The former in-repository benchmark harness has been superseded by
[codex-setup-ab](https://github.com/yusing/codex-setup-ab). Use that repository
for setup, execution, grading, and reporting of controlled Codex comparisons.

Mekugi retains its runtime [capture metrics contract](spec/metrics.md); the
comparison runner and its methodology are owned by codex-setup-ab.
